# Namenyx

Namenyx is a modular Windows desktop platform for Twitch stream tools and integrations. Features are installed as independently updateable modules, so users only download what they choose to use.

## Download

Download the latest Windows setup file from the [latest release](https://github.com/shishiawase/Namenyx/releases/latest).

Use the `Namenyx_<version>_x64-setup.exe` asset. The `latest.json` and `.sig` files are updater metadata used by the application.

## Updating

Versions with updater support can check and install updates from this release channel. Older builds without updater support must be replaced manually once by installing the current setup file.

Official modules are distributed separately through the preconfigured Namenyx module source. Third-party sources and modules are optional and are governed by their publishers' terms.
